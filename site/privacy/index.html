◎Samsarix Page Lens

Privacy disclosure

Page Lens creates source-triage briefs locally. It has no account system, analytics, advertising, remote AI service, telemetry, or page-content upload.

Effective August 1, 2026

Who operates Page Lens

Samsarix Page Lens is developed by Samsarix LLC. Privacy questions can be sent to contact@samsarix.com; support and private security-channel requests can be sent to support@samsarix.com.

When processing begins

Processing begins only when the user selects Create page brief on a normal HTTP or HTTPS page. Unsaved page text exists only in memory while the extension popup is active.

What is processed

The bounded extractor may process page text, title, sanitized URL, description, declared HTML language, headings, paragraphs, links, citation-like markup, visible byline/date metadata, and up to 20 unique external source domains. It visits at most 15,000 DOM nodes and retains at most 250,000 characters.

It skips scripts, styles, navigation, footers, forms, dialogs, templates, and elements explicitly marked hidden or aria-hidden="true". It does not inspect form values. CSS-only hidden text may still be encountered.

Language and readability

The English readability formula runs only when a page explicitly declares English. Declared non-English and undeclared-language pages retain Unicode-aware word, frequent-term, structure, and source analysis, while readability is shown as unavailable. No remote language detection occurs.

Storage and retention

Nothing is saved automatically. Selecting Save locally stores a schema-v2 brief in chrome.storage.local. History is deduplicated by sanitized page URL, capped at 25 briefs, and remains until the user clears it or removes the extension/browser profile.

A brief contains structured counts and scores, visible metadata, frequent terms, an outline, external source domains, timestamps, and an excerpt of at most 280 characters. URL credentials, query parameters, and fragments are removed before storage or export. Paths, titles, metadata, and excerpts can still be sensitive.

Chrome shares chrome.storage.local between regular and Incognito extension contexts. Saving in Incognito therefore adds the brief to the same persistent history available during regular browsing.

Comparison and export

Two-brief comparisons are computed locally and are not stored automatically. Copy, Markdown, and JSON export require explicit user action. After export, the system clipboard or browser download behavior controls the resulting data.

Permissions

  • activeTab gives temporary access only to the invoked tab.
  • scripting runs the bounded extractor after explicit action.
  • storage retains user-requested briefs.

Page Lens requests no host permissions and installs no background worker or always-on content script.

Changes

Any future remote processing requires an architecture, permission, store-declaration, and disclosure review before release. The canonical source disclosure is maintained with the extension in docs/PRIVACY.md.
